# EV Route contributor guidance
Read README.md and HANDOFF.md before changes. Preserve the zero-charge requirement: no paid APIs, billing activation or paid hosting without explicit authorization. Never silently replace a failed live request with sample data. Keep sample and estimated data visibly labelled. Preserve ordered complete-route Google Maps export and the mobile waypoint fallback. Run `node --test tests/*.test.mjs` for energy/planning/export changes. Do not commit credentials, browser state, personal trip history, deployment credentials or the original Sites project identity.
